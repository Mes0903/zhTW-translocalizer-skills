# zhTW Translocalizer Skill

Standalone AgentSkill for Taiwan Traditional Chinese translation, rewriting, review, and linting workflows.

Install this repo as a skill root. In `hanaya-workspace`, it is mounted at:

```text
skills/zhTW-Translocalizer/
```

The skill's required entrypoint is `SKILL.md`; references, linter scripts, and style assets are kept beside it.
